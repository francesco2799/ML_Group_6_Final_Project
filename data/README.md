# Data

This folder contains the raw and cleaned HMDA datasets.

These files are not tracked by Git due to their size. Download the 2024 HMDA Modified LAR data from:
https://ffiec.cfpb.gov/data-publication/modified-lar/2024

After running the data cleaning code from the proposal, place the cleaned dataset here.

## RQ3 – Temporal Stability Analysis

This section analyzes mortgage approval disparities using HMDA data from 2022 to 2025, with a focus on whether these disparities remain stable over time.

Data Access:

Due to file size constraints, the full HMDA datasets (2022–2025) are not stored in this repository. All raw and cleaned datasets used for RQ3 can be accessed via the shared Google Drive folder: https://drive.google.com/drive/folders/1W80sZma7d-KfLuvUjI-VZt6dOOj_dFRZ

Notes:

- The cleaned dataset used for RQ3 analysis is `hmda_2022_2025_cleaned_for_rq3.csv`
